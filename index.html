About

I build backend systems and full-stack applications for businesses that need software to actually hold up in production — not just demo well. Most of my work sits in the .NET ecosystem: ASP.NET Core, C#, Entity Framework Core and SQL Server, paired with React or Angular on the frontend when the project calls for it.

Over the last 4.5+ years I've worked across ERP and CRM platforms, a travel booking engine, a real-time multiplayer gaming API, and retail/energy management systems. A recurring part of my work is taking something slow or fragile — a legacy stored procedure, a VB.NET desktop app, an N+1 query problem — and rebuilding it into something that scales.

I've also led a 5-person development team, mentored junior developers, and worked directly with non-technical clients to turn vague requirements into working systems. I'm comfortable owning a project end-to-end: architecture, database design, API implementation, and deployment.
